# Valentine Jeffery

Civil engineer building personal applications, calculations, and domain tools with Antigravity.

## About

- Profession: Civil Engineer
- Focus: Translating civil engineering design criteria, formulas, and workflows into practical software tools.
- Development: Building and testing personal engineering applications in Antigravity.

## Areas of Focus

- Structural analysis and calculation tools (beam mechanics, shear, bending moment, and deflection).
- Hydrology and stormwater runoff estimators (Rational Method and flow capacity).
- Materials estimation utilities (concrete mix design, quantities, and rebar schedules).
- Earthwork, cut-and-fill, and slope stability estimators.
- Converting engineering spreadsheets and manual workflows into interactive apps.

## Workflow

Applications are developed locally using the Antigravity IDE and cloud execution environments, with project files version-controlled and archived here on GitHub.
